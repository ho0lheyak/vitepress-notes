# 为什么静态站点又流行起来了

动态 CMS 统治了十几年，静态站点却在这几年重新回到视野。原因不复杂。

## 三个驱动力

1. **内容所有权**
   内容存成文件，就永远是你的。平台倒闭、改价、下架，都不影响你手里那份 Markdown。

2. **成本结构**
   静态文件可以放在任何地方 —— GitHub Pages、对象存储、一台最便宜的 VPS。没有数据库，没有运行时。

3. **工具链成熟**
   构建快、热更新快、还能在 Markdown 里写组件，写文档的体验已经不输给富文本编辑器。

## 代价也要说清楚

- 需要会用 Git 和命令行，对非技术同事是门槛
- 没有"点一下就能改"的在线编辑（除非另接 CMS）
- 评论、搜索这类动态功能需要额外方案

## 一句话总结

> 静态站点不是技术复古，而是把"内容"和"呈现"重新拆开的一次纠偏。
