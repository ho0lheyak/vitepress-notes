# ?.
c#特有空值条件访问符，简化先判空再调用
A?.B
A为null（空）吗，如果是空表达式返回null；如果A不为空，执行B。

# 事件的概念

event(事件)就是对委托的封装（语法糖）。编译器负责包装委托只对外开放订阅和取消订阅，不支持外部直接赋值（覆盖）。

先声明一个委托
```c#
public delegate void ProcessCreatedHandler(int pid);
```
再使用事件封装
```c#
public event ProcessCreatedHandler ProcessCreated;
```
有event的就是发布者，不知道外部谁订阅，只负责适合实际调用函数；订阅者通过+=，-=来进行订阅和取消；订阅者是外部代码，只负责注册回调方法

# 对比
c#的事件（发布-订阅者关系）是消息通知/回调注册机制，有点像MATLAB句柄函数。

# 使用
c#不推荐使用自定义事件；一般用非标准事件action等和标准事件EventHandler等

# java
java没有内置event关键字，可以自己写这套发布/订阅的回调思想，本质就是设置一系列回调句柄，满足条件时逐个执行
