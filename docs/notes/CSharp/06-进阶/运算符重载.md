语法：
public static vector(类名) operator +(要重载的运算符)(根据运算符传入参数量)

不是所有运算符都能重载
![运算符重载](/csharp/运算符重载.png)

# java
完全不支持运算符重载，被刻意砍掉防止产生难以理解的代码

# 概念对比
方法重载是对同名方法不同参数的修改
运算符重载是给符号增加自定义逻辑，实现即使是在自定义类也能通用运算符
