# ref与out
c#的ref引用与c++在语义上非常接近，但是底层实现上有区别导致语法有差异。
c#的ref参数是托管引用（即受GC保护的），c++是左值引用，c++的不可重定向，c#的可以重新绑定
```c#
int x = 10;
ref int r = ref x;
//右侧ref x是取存储位置不是变量修饰符，一元运算符获取x的存储位置
//同时ref int r声明局部变量r，r的类型是对int存储位置的引用；如果写r = x意思是把x赋值给r，r又是指向内存
//这里做了语法糖使用的时候写名字已经包含了解引用，写名字就是访问内存槽，隐式解引用
```
c#的class引用是对象引用，引用堆上的对象实例，ref是引用变量/内存槽的

# in/out（方法参数修饰词，描述参数以什么方式传递）
in int a：只读 ref，相当于 C++ const T&，只能读不能写
out int a：ref 的变体，要求方法内必须赋值
