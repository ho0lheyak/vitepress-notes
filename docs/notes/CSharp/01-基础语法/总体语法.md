# c#9分割
之前必须使用命名空间包含整体；之后可以直接namespace ;，文件范围命名空间。
namespace必须写在using之后，类型定义之前，且限定单文件使用1个，不能再嵌套其他的。

# Main
全局静态函数，程序执行的入口
static void Main。名字必须是开头大写的Main，必须是static，返回值是void或int，参数可选（string\\[\] args）

使用顶级语句可以不写Main直接写在最外面。
