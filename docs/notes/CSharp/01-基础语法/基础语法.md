# if-else和switch
if-else语法和switch语法在c#和java中相同，细节有一点区别

c#不能switch不带break（隐式穿透），c#认为这不安全；java允许
c#的if条件可以用模式匹配
**但都只允许if放布尔表达式而非数字**

现代switch表达式支持模式匹配，模式n，把匹配到的值绑定到变量n
现代switch写法-java箭头switch，不用写break
```java
//原本的写法{}就是switch语句主体，}表示结束
int x = 2;
String res = switch(x){
	case 1 -> "one";
	case 2 -> "two";
	default -> "three";
}
```
现代c#写法-=>箭头switch，c#\_可以作为弃元（接收到这个匹配的值，不想起变量名，不适用它）充当default
```c#
//现代的写法是叫switch表达式，;表示结束
int x = 2;
String res = switch(x){    //c风格传统switch关键字在前括号包变量
	case 1 => "one";
	case 2 => "two";
	_ => "three";     //不管什么值都匹配，不绑定变量
}
//进阶
object o = 12;
string res = o switch   //c# 8待匹配的值+switch关键字
{
    int n when n < 10 => "小于10，n是" + n,   //模式匹配：类型模式+when条件守卫
    int n when n >=10 => "大于等于10，n是" + n, //int n 检查o对象是否为int;如果是就绑定到新变量n，when n < 10条件首位，在类型匹配成功后附加布尔判断。java不具有when
    string s => "字符串：" + s, //c#理string+其他类型，其他类型都会自动调用.ToString()以实现字符串拼接
    _ => "别的类型"  // 所有剩下的，不取出变量
};
```



# for和while循环
while循环c#和java几乎相同（以及do-while）；传统三段式for(初始化;条件;迭代)也相同

增强for(类型 变量：容器) 与c++类似后面引入，只读迭代；当不需要下标索引、顺序访问、不修改迭代对象时优先实用，代码简洁优美
```java
//java的和c++类似
int [] arr = {1,2,3};
for(int num : arr){
	system.out.printIn(num);
}
```
c#是范围foreach
```c#
int[] arr = {1,2,3};
//in关键字
foreach(int num in arr){
	console.WriteLine(num);
}
//后面c#11补充了语法糖
int [] arr = {1,2,3};
for(int num : arr){
	system.out.printIn(num);
}
```

# 循环控制:break/continue
完全一致，并且相较于C++额外支持标签循环（即带名字的break/continue），例如 break outer直接跳出外循环不只是内循环；
补充：c#的goto只能跳到同一方法内的标签，不能跨方法
