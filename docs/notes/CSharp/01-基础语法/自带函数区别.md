实例属性和静态方法
其实就是一个是实例加点调用
一个是直接调用
# 一句话结论

**不是继承！数组并没有继承`Array`然后获得`.IndexOf`实例方法；`Array.IndexOf`是静态方法。**

## 1. `Array.IndexOf(nums, sum)`

```
int[] nums = { 1,3,5 };
int idx = Array.IndexOf(nums, 3);
```

- `Array` 是**类名**（系统的 `System.Array`）
- `IndexOf` 是它的**静态方法**
- 调用方式：`类名.静态方法(参数)`，**不是对象.方法**
- 把数组`nums`作为**第一个实参传给静态函数**

对比：

```
// List的实例方法：调用者是list对象
list.IndexOf(val);  

// Array静态方法：Array是类，nums只是传进去的参数
Array.IndexOf(nums, val); 
```

## 2. 数组和 `System.Array` 的关系（重点，很多人混淆）

C#里：

> 所有数组类型（`int[]`、`string[]`）**隐式派生自 `System.Array`** ✅ 确实是继承关系！ 但是！**继承来的是实例成员，`IndexOf`不是实例方法，是静态方法！**

### 区分两个东西

1. **实例成员（从Array继承来，可以用数组实例调用）**

```
int[] arr = {1,2,3};
int len = arr.Length;       // 实例属性，继承自Array
long longLen = arr.LongLength;
```

你可以直接 `arr.Length`，因为这是**实例属性**，数组对象本身拥有。

2. **静态方法，属于Array类本身，不属于数组实例**

```
Array.IndexOf(arr, value);
Array.Sort(arr);
Array.Reverse(arr);
```

❌ 不能写 `arr.IndexOf(value)`！数组实例没有IndexOf这个实例方法！ 哪怕数组继承了`Array`，**静态方法不会被继承成实例方法**。

> 继承：是**对象**拥有父类的实例成员。静态成员属于类，不属于实例，不会变成对象的方法。

## 3. 类比理解

```
// Array是模板类
public class Array
{
    // 静态方法：属于Array这个类，不是数组对象的
    public static int IndexOf(Array array, object value)
    { ... }

    // 实例属性：每一个数组实例都自带
    public int Length {get;}
}
```

`int[]` 是子类，继承`Array`，所以每个`int[]`实例都有`Length`。 但是`IndexOf`是static，归`Array`类，不归实例。

## 4. 容易踩坑对比

```
int[] nums = {1,2,3};
nums.IndexOf(2); // ❌ 编译报错！数组实例没有IndexOf实例方法

List<int> lst = new(){1,2,3};
lst.IndexOf(2);  // ✅ List自带实例方法IndexOf
```

## 快速复习小结

1. C# 所有数组 `T[]` **隐式继承自 `System.Array`**（继承关系成立）
2. `Length` 是**实例属性**，继承过来，所以 `nums.Length` 可以直接写
3. `Array.IndexOf`、`Array.Sort` 是**静态方法**，属于`Array类`，**不是数组对象的成员**
4. 调用静态方法格式：`Array.IndexOf(数组变量, 查找值)`，数组只是传入的参数，不是调用主体。
