# <>引入
<>叫做语法分隔符/类型参数括号，不是运算符。更不是标签。
在list&lt;int&gt;,vector&lt;int&gt;是泛型参数列标的定界符，用于包裹类型参数。
list，vector叫做泛型模板，&lt;int&gt;表示实例化这个模板并替换类型参数为int。
语法解析：c++11后支持连续尖括号，即`vector<vector<int>>`
写完泛型+限定后就和普通变量使用一样

# 运行解析
①c++：模板。在编译器进行文本替换，实例化多套独立的代码
②c#，.NET泛型，运行时泛型由CLR支持。值类型独立代码，引用类型复用一套代码
③java，Type Erasure 类型擦除，编译器伪装，编译后抹掉泛型信息。
c++才叫模板，c#/java都是泛型，作用一样底层实现不一样。


# 泛型语法
struct/class name&lt;T&gt;{
//用T替换所有想使用到泛型的地方
}
## 使用
①与vector等一样
②可以设置接受多个参数，写成T1，T2
③方法也可以是泛型，语法一样，在名字后加上&lt;T&gt;
④调用泛型的时候编译器可以自动识别类型，不是必须添加上<>

# Action
泛型类型的委托——不返回任何类型，只执行行为

# Func
带返回值的泛型委托

# 谓词Predicate
特化过的Func，返回值固定+传参只有一个
