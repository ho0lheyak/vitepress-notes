公开字段（变量的别名）：
==public int age;==

定义：抽象类的静态数据的访问接口
用于解决私有字段的访问问题，通过公开的函数访问私有的函数。
# 手写属性（底层）
属性命名规则：与负责的变量名字相同，首字母大写

# 自动属性
语法糖自动生产访问器
prob name（property属性）
同时产生私有变量name和name的属性访问器，不需要再先写私有变量，然后定义访问器；缺点：不能自定义函数逻辑，set和get逻辑固定

# java的替代
javac++python没有没有自动属性语法糖，java一切都是普通成员方法，需要手写getter和setter
