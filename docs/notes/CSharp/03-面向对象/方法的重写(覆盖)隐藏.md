加入virtual、override关键字后，运行时会根据实际对象类型按虚方法表会去找子类的方法
属性本质也是方法，override和属性都可以被重写

# abstract
abstract就是virtual更小型版本，适用于没有任何方法体的父类方法，存在意义只是为了被重写。

# java的重写

java默认所有实例方法是虚方法（没有static、private、final）。c#相当于手动添加virtual和override
