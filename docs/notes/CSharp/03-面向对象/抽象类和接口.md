# c#和java
抽象类的语法：在类名前加上关键字abstract。表明这个类里面所有的方法都只是继承使用，**不能去创建这个类的实例。**
方法前加上abstract表明这个方法必须由子类实现，并且方法前加了abstract一定也会让类加上abstract。（防止被实例化调用一个抽象方法）

# 接口
接口是一种规范，不提供具体实现，只是承诺会去写；抽象类可以提供一些公有的实现，核心是不能实例化。
语法：
```c#
	interface animal{
		void sort();
	} 
```
类实现接口
```c#
	class dog:animal{
		public void sort(){
			Console.WriteLine("a dog");
		}
	}
```
```c#
animal s1 = new dog();
s1.sort();
//这里体现了接口多态：变量类型是接口，实际对象可以是任意实现它的类
```

# 关键点：
①C# 类只能继承一个父类（单继承），但接口无数量限制，这是接口最大用处。
②接口所有成员都是隐式public的
③创建接口对象的时候，和抽象类相似。
编译器时候，看到变量声明类型animal，写的成员只有sort()，当运行时看到具体对象s1指向堆上完整的dog对象，确实包含speak()对象但是无法使用。编译的时候就无法通过，因为一维是animal对象（**和父类、子类使用规则一致**，类继承是is-a，接口是can-do）

c#/java禁止类的多继承根本是c++/python会产生菱形继承问题；如果是接口实现，会要求写上具体是哪个接口要求实现的函数
