# c#和java
抽象类自己不能 new，但是子类实例化的时候，一定会调用抽象父类的构造函数。 构造函数不是给抽象类自己实例化用的，是给子类在构造自己对象的时候，用来初始化继承来的那一部分成员。

# 规则
==不写父类构造函数只写子类的构造函数的时候，编译器自动生成无函数体构造函数==
父类的成员变量尽量由父类自己赋值，protected还可以单独在子类写赋值，如果是private子类即根本无法获得父类成员变量

# C# 示例，分4个最简单场景

> 核心记住一句话：抽象类不能 `new`，但是**子类new的时候，一定会跑抽象父类的构造**，用来初始化属于父类的那部分字段。

## 场景1：抽象类写了无参构造，子类隐式调用 base()

```
// 抽象类，不能 new Animal()
abstract class Animal
{
    public string Name;

    // 抽象类的构造函数
    protected Animal()
    {
        Name = "未知动物";
        Console.WriteLine("【抽象父类Animal构造】执行");
    }
}

class Cat : Animal
{
    public Cat()
    {
        Console.WriteLine("【子类Cat构造】执行");
    }
}

// 测试代码
Cat c = new Cat();
```

输出：

```
【抽象父类Animal构造】执行
【子类Cat构造】执行
```

解释： 写 `new Cat()`，先自动调用父类 `Animal()`，再跑Cat构造。 虽然我们没有写 `:base()`，编译器会自动加上。 我们**永远不能写 `new Animal()`**，但构造函数照样会被子类调用。

---

## 场景2：抽象类是有参构造，子类必须手动写 base传参

```
abstract class Animal
{
    public string Name;

    // 抽象父类：有参构造，不再有无参默认构造
    protected Animal(string name)
    {
        Name = name;
        Console.WriteLine($"【Animal构造】名字={name}");
    }
}

class Cat : Animal
{
    // 子类构造必须用 base 调用父类有参构造
    public Cat(string name) : base(name)
    {
        Console.WriteLine("【Cat构造】");
    }
}

// 测试
Cat c = new Cat("咪咪");
```

输出：

```
【Animal构造】名字=咪咪
【Cat构造】
```

解释： 抽象类要求创建动物时必须给名字。 所有子类（Cat、Dog）创建时，都要把名字交给抽象父类构造，统一初始化 `Name`。 👉 父类的初始化逻辑只写一次，所有子类复用。

## 场景3：抽象类有构造 + 抽象方法（经典组合）

```
abstract class Animal
{
    public string Name;

    protected Animal(string name)
    {
        Name = name;
    }

    // 抽象方法：子类必须重写
    public abstract void Speak();
}

class Cat : Animal
{
    public Cat(string name) : base(name)
    {
    }

    public override void Speak()
    {
        Console.WriteLine($"{Name}：喵");
    }
}

// 测试
Cat c = new Cat("咪咪");
c.Speak();
```

输出：

```
咪咪：喵
```

解释： `Name` 这个字段是父类的，存在于Cat对象内存里。 所以创建Cat的时候，父类构造要负责填充 `Name`。

## 场景4：抽象类没有任何 abstract 方法，但依然有构造函数

> 这个就是刚才说的：抽象类只是禁止直接new，所有方法都有实现

```
abstract class Animal
{
    public string Name;
    protected Animal()
    {
        Name = "无名";
    }

    // 没有抽象方法！全部是普通方法
    public void Sleep()
    {
        Console.WriteLine($"{Name}睡觉");
    }
}

class Cat : Animal
{

}

Cat c = new Cat();
c.Sleep();
```

输出：

```
无名睡觉
```

解释： Animal 没有抽象方法，但是标记 abstract，所以不能 `new Animal()`。 但子类Cat new的时候，依然会调用Animal构造，给Name赋值。

# 总结一句话

当你 `new Cat()`，在内存里生成的对象 = `Animal那部分内存 + Cat新增的内存`。 `Animal` 的那部分成员，由抽象父类的构造函数负责初始化。 抽象类构造**不是给抽象类自己new用的，是给子类对象里面父类那一块数据初始化用的**。

# 额外小坑（面试常问）

抽象类构造函数里面**可以调用抽象方法**，但是强烈不推荐！

```
abstract class Animal
{
    protected Animal()
    {
        Speak(); // 这里调用抽象方法！
    }
    public abstract void Speak();
}
class Cat : Animal
{
    string msg = "喵";
    public override void Speak()
    {
        Console.WriteLine(msg);
    }
}
// new Cat() 会输出空！
// 原因：父类构造执行的时候，子类字段msg还没初始化！
```
