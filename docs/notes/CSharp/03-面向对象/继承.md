组合有继承的优点，优先组合
继承优点复用，缺点强耦合

c#不允许多重继承（多个父类），不限制继承次数（继承链）
语法：类名加冒号
```c#
public class animal{
	public void Say(){
	Console.WriteLine("an animal");
	}
}
class cat:animal{
	public void Speak(){
	console.WriteLine("cat");
	}
}
```
# 构造函数继承规则
①子类构造优先调用父类构造
②默认调用无参构造
③父类没有无参构造时，子类必须使用base关键字指定调用哪一个父类构造函数

1. 隐式base，父类是无参构造（构造函数不传入参数）。编译器会自动补充base()
2. 父类是带参构造，子类必须base(10)显示调用。
base()写在子类的构造函数的函数体前
3. ```c#
//可以有多个构造函数的时候
class Parent
{
    public Parent() => Console.WriteLine("父无参");
    public Parent(int x) => Console.WriteLine($"父 x={x}");
}

class Child : Parent
{
    public Child() : base() { } // 调用父无参，可以省略 base()
    public Child(int a) : base(a) { } // 调用父带参构造
}
//4.如果将这里的base()改为this，会调用当前类别的另一个构造，即子类的构造，base(a)
```
5. 静态构造函数不会被继承，也不能被this/base调用
6. 构造函数不能被override重写，当然也不能用virtual
