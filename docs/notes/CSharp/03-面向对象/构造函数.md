# 对比
与python相同。this不是c++的指针（this->），是对象引用
①静态方法没有this
②用于消除名字遮蔽，即局部变量和成员同名的时候才用，没歧义不写this

java与c#相同


# 构造器的init字段
添加init字段后的自动构造器，就只允许在构造函数里（即对象初始化时）赋值


# 结构体写法初始化
在new一个对象的时候改分号为花括号{}，里面添加初始化赋值。

# 补充
 如果一个类没有写任何构造函数，编译器就会自动补充一个无参protected的构造函数
