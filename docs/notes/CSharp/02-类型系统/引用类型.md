声明引用类型：类似struct概念，给人字节写代码定义新的引用类型
内置：CLR预先定义好
![引用类型](/csharp/引用类型.png)
- `record` 本质也是 class 的语法糖，属于你声明出来的引用类型；
- `interface` 引用类型，只能定义契约，不能实例化；
- `delegate` 用来定义委托类型（函数签名类型）。


1. `object`：所有类型的根，顶层基类。`System.Object`
2. `string`：字符串类型，`System.String`，引用类型，有特殊的字符串常量池行为。
3. `dynamic`：不是一个真实类型，是编译期标记，告诉编译器**关闭静态类型检查，运行时解析**；底层仍然是`object`。
