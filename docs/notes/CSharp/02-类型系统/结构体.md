和类区别：
①最本质是一个值类型一个引用类型
从内存角度
即默认分配在栈，装箱后进入堆；
引用是栈上分配一个，指向堆已经有的一个。
从使用角度
拷贝一个对象后，值是直接复制一个，不干涉原本的，类是都指向一个，会干涉原本的

②变量默认的一个public一个private
③结构体使用前必须初始化。如果没有手动初始化每个变量就不允许通过编译，如果初始化了相当于调用了构造函数，不需要手动写构造函数会默认创建一个，把值全赋0
④工程上，一般struct放值，class才放函数
⑤int、double、float本质是结构体；结构体隐式密封sealed。
# java
没有struct关键字，都是class

# c++
c#的struct区别比c++更加大，c++几乎可以说一样，c#不允许继承任何类
