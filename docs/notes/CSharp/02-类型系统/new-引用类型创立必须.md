c++的new是malloc的升级，在堆上分配内存，返回裸指针，需要手动用delete管理内存
c#的new是创建托管堆上的对象，返回对象的引用，由GC自动回收（不用也不能用delete），没有指针，用的多了GC性能下降

c++引用的不同变量名字仅供编译器查看，编译期经过符号表处理就没了
c#没有指针，c#的引用可以认为是安全，受CLR管控的智能指针。java也没有
底层可以认为是解引用

c#和java的对象引用不是c++的别名，c++是纯粹的别名，两个名字不同是连底层的指针地址和指向内容都相同。但是c#和java的是不同名字的引用连底层的指针地址不同，只是指向相同，c++指针才和c#，java的类似

c#的结构体和class都是引用类型，c++的是值类型。java也是


`new int[5]` 新建出来的**数组实例，天生自带一整套属性、方法**，这些是从 `System.Array` 继承来的。 `new` 在堆上创建的不只是一段存数字的缓冲区，而是**完整的数组对象**：对象头 + 长度信息 + 元素缓冲区 + 类型虚方法表（用来调用继承来的所有方法）。




# 除此以外
new还有显示声明子类方法优先，**隐藏**父类方法的作用(没有进行重写，与虚函数表无关，这里不使用就会提前到编译期而非运行时)，语法为
public new object GetValue(int index);
等价为
public override object GetValue(int index);
