## 第三条：由语言或库定义的安全结构转换

这是一类**语言 / 库预先定义好、保证安全**的自定义隐式转换，不是基础数值、不是继承向上转型。 有两类典型例子：

1. **隐式装箱（C# 特有）**：值类型 → object

```
int a = 10;
object o = a; // 隐式装箱，int值类型隐式转为object引用
```

2. 库里面重载的隐式转换运算符 `implicit operator`（程序员 / 库作者自己定义的安全隐式转换）

```
struct Vector2
{
    public int X,Y;
    public static implicit operator Vector3(Vector2 v)
    {
        return new Vector3(v.X, v.Y, 0);
    }
}
```

之后就可以直接写：

```
Vector2 v2 = new Vector2();
Vector3 v3 = v2; // 隐式调用库定义的转换，不用强制转换
```

> 一句话理解第三条： 不是基础数值拓宽、也不是继承向上转型，而是**语言或者库预先写好、承诺安全的自定义隐式转换规则**。
